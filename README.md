## Featured project

### GCoins

A custom Minecraft economy plugin written in Java.

GCoins was built as a complete economy system rather than just another `/money` command.

**Features include:**

* Player balances
* Money transfers
* Transaction history
* Interactive economy GUI
* Offline player support
* Database storage
* Economy integrations
* Configurable messages and settings

The project is designed for modern Minecraft servers and focuses on keeping the codebase modular and easy to extend.
